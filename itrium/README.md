# Itrium

Everything in this directory applies to [Itrium](https://github.com/itriumid)'s own projects and
to nothing else. The rest of the handbook is written to be used on any project; this is the part
that isn't. On a project that isn't Itrium's, skip this directory — nothing outside it depends
on it.

| Path | What it is | Read it when |
|---|---|---|
| `engineering.md` | Rules that hold for Itrium's projects on top of `conventions/rules/engineering.md`. | writing prose, comments or names; building an interface |
| `brand.md` | Reference: the colors, the typefaces, the logo. | choosing colors, or designing anything visual |
| `decisions/` | Technology and infrastructure choices that affect more than one of Itrium's projects. | when it matters, or before proposing a new one |

An Itrium project is sent here by the section `scaffold/itrium/agents-section.md` adds to its
`AGENTS.md`. A project without that section is never pointed here.

The handbook's writing rules hold here too: `engineering.md` is rules and leads with the
imperative, `brand.md` is reference, and `decisions/` follows its own
[`README.md`](decisions/README.md).
